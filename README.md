# 번짐 · Inkbloom

잉크가 **박자에 맞춰** 번지고, **같은 박자에 만난 색**은 섞이는 세로형 모바일 타이밍 퍼즐입니다.
어디에, 언제 떨어뜨리느냐로 색이 만나는 자리를 설계해 그림을 완성합니다.

`reference/` 의 프로토타입에서 핵심 재미(번짐·만남·섞임)만 가져와 처음부터 다시 만들었습니다.

## 실행

빌드 없이 정적 파일로 동작합니다.

```bash
# 아무 정적 서버나 사용
npx serve .            # 또는 python3 -m http.server
# 혹은 index.html 을 브라우저로 바로 열어도 됩니다 (file://)
```

`?level=N` 을 붙이면 N번째 레벨로 바로 들어갑니다(개발용).

## 규칙

- 빈 칸을 누르면 큐의 다음 잉크가 떨어집니다. **첫 방울을 떨어뜨리는 순간 시간이 흐르기 시작**합니다.
- 박자마다 잉크가 상하좌우로 한 칸씩 번집니다. 박자와 박자 사이에 떨어뜨린 방울은 다음 박자부터 번집니다.
- 서로 다른 색이 **같은 박자에** 빈 칸에 닿으면 섞입니다(빨+노=주황, 노+파=초록, 빨+파=보라, 셋이면 탁한 먹색). 섞인 칸은 더 번지지 않아 벽처럼 막습니다.
- 먼저 온 색이 칸을 차지하고, 칠해진 칸은 다시 바뀌지 않습니다.
- 표시된 목표 칸을 모두 맞는 색으로 물들이면 완성입니다.

장마다 규칙이 하나씩 추가됩니다: 우물(정해진 자리에만 떨어뜨림), 벽, 잠든 잉크(닿으면 깨어남), 짧은 잉크(숫자만큼만 번짐)와 비워 둘 칸, 두꺼운 종이(한 박자 더 쉬어 감).

## 설계 메모

**타이밍이 핵심, 실패는 판단의 결과**
- 입력은 박자 단위로 양자화됩니다. 한 박자(약 0.6~0.76초) 안이면 언제 눌러도 결과가 같으니 반응속도가 아니라 *몇 번째 박자에* 떨어뜨릴지가 관건입니다.
- 다음 박자에 번질 자리가 미리 스며 보이고, 목표가 다음 박자에 틀어질 상황이면 목표 둘레에 경고 테두리가 돕니다.
- 실패하면 원인과 고칠 방향을 한 줄로 알려 줍니다("파랑이 먼저 도착했어요 / 파랑을 조금 더 늦게, 또는 더 멀리"). 다시 하기는 즉시이며, 직전 시도의 낙하 위치·박자가 흐린 표시로 남습니다.
- 모든 레벨은 오프라인 솔버(`tools/solver.js`)가 전수 탐색으로 풀이 가능함을 증명하며, 저장된 힌트 해답은 두 방울을 같은 박자에 떨어뜨릴 필요가 없는 것으로 고릅니다.

**보는 즐거움**
- 수채화 렌더러: 잉크 레이어를 종이 위에 곱하기(multiply)로 합성하고, 번짐 결·얼룩·가장자리 짙어짐을 더합니다. 다른 색 사이에는 종이 한 올을 남겨 작은 화면에서도 칸 구분이 분명합니다.
- 소리는 모두 Web Audio로 합성하며 D 장조 5음계에 맞춰져 있어 번짐·섞임·목표 달성이 박자 위의 음악이 됩니다. 진동은 낙하·섞임·달성·실패에 각각 다른 패턴입니다.
- 완성하면 빛이 종이를 훑고, 연필 격자가 사라지고, 액자 테두리와 낙관(서명 도장)이 찍힙니다. 팝업 없이 하단 버튼만 "다음 장"으로 바뀝니다.

**처음 켠 사람**
- 첫 실행은 메뉴 없이 바로 1-1로 들어가 "눌러 보세요" 표시만 보여 줍니다. 1장은 탭 → 두 색 → 섞임(거리) → 기다림(타이밍) → 자유 배치 순으로 한 가지씩 가르칩니다.
- 새 규칙이 나오는 판에는 상단에 한 줄짜리 태그만 뜹니다.

**레벨 (72개, 6장 × 12)**
- 장마다 도입 → 연습 → 쉬어 가는 판 → 발견이 있는 판 → 어려운 판의 강약이 있습니다(예: 2-6 미로, 4-6 봉인).
- 막히면: 3번 실패 후 힌트 버튼이 빛나고, 힌트는 한 방울씩 위치와 박자(카운트다운 표시)를 보여 줍니다. 한 판을 건너뛰어도 그다음 판이 열립니다.

**메타**
- 스케치북: 완성한 판마다 *내가 칠한 그대로의* 그림이 모입니다. 힌트 없이 완성하면 빨간 낙관이 찍힙니다. 한 장을 다 채우면 새 종이(한지·크라프트 등)를 얻어 판의 바탕을 바꿀 수 있습니다.
- 오늘의 한 장: 날짜마다 같은 퍼즐(월·화 가볍게, 수~금 보통, 주말 도전). 그림 일기 달력에 그날의 그림이 쌓이고 연속 기록이 표시됩니다. 지난 날짜도 그릴 수 있지만 연속 기록에는 들어가지 않습니다.

**접근성**
- 색 기호: 점 위치가 원색(위=빨강, 왼쪽 아래=노랑, 오른쪽 아래=파랑)이고 섞인 색은 점 두 개 — 섞임 규칙 자체를 기호로 읽을 수 있습니다. 목표와 잉크 칩에는 항상 표시됩니다.
- 색 구분 도움 모드: 색맹 친화 팔레트 + 모든 칸에 기호 표시.
- 박자 빠르기 "느긋하게"(×1.45), 소리/진동 끄기, 한국어/English.
- 조작 버튼은 모두 화면 아래쪽(엄지 영역)에 있고, 판도 아래쪽으로 치우쳐 배치됩니다.

## 구조

```
index.html, css/style.css
js/sim.js       결정론 시뮬레이션 (브라우저·Node 공용)
js/render.js    수채화 판 렌더러, 썸네일 그림
js/audio.js     Web Audio 합성음 + 진동
js/game.js      플레이 컨트롤러 (박자, 낙하, 승패, 힌트, 실패 원인)
js/ui.js        화면/진행/메타 (홈, 스케치북, 그림 일기, 설정)
js/levels.js    생성물: 72개 레벨 (tools/build.js)
js/daily.js     생성물: 오늘의 한 장 풀 + 날짜 → 퍼즐
tools/          솔버, 생성기, 레시피, 빌드, 후보 풀(pool/)
tests/          Playwright 자동 플레이/스크린샷, 일일 퍼즐 검증
```

## 레벨 파이프라인

```bash
node tools/pool.js c2_rb,c3_two 30 1     # 레시피별 후보 생성 (해답 먼저 → 목표 칸 선택 → 난이도 측정)
node tools/review.js c2_rb 10            # 후보 보기
node tools/build.js                      # 모든 레벨 재검증 후 js/levels.js, js/daily.js 생성
```

## 테스트

```bash
NODE_PATH=$(npm root -g) node tests/play.js 1 72   # 실제 UI에서 박자에 맞춰 탭해 72개 레벨을 모두 푼다
node tests/daily-check.js                          # 3년치 오늘의 한 장이 모두 풀리는지
NODE_PATH=$(npm root -g) node tests/screens.js /tmp/out   # 메타 화면 스크린샷
```
